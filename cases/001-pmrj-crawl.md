# 真实踩坑记录（持续更新）

> 本目录记录用 dsh-xhs-collector 真实采集过程中遇到的具体问题和解法。

## 案例 001：完美日记 30 天采集实战

**任务**：采集 8 个关键词，共 1000+ 条笔记

**踩坑**：
1. **第一轮**：公共 IP，5 个关键词后触发滑块验证码，全部失败
2. **第二轮**：换住宅 IP，但 1 分钟内连发请求，又被限流
3. **第三轮**：加 `delay_between=3` 秒，200 条左右又触发风控
4. **最终方案**：每个关键词之间间隔 8 秒，单关键词分批 50 条拉

**结论**：批量采集必须模拟人工节奏，每 50 条停 30 秒。

**耗时**：从 0 经验到稳定运行 2 小时

## 案例 002：xsec_token 失效

**问题**：周五采集的数据存了笔记 URL，周一打开全部「内容不存在」

**原因**：xsec_token 24 小时过期

**解决**：采集时同步抓取笔记正文，URL 仅作 ID 索引

## 案例 003：去重逻辑

**第一版**：按 noteId 去重，但发现同一篇笔记被收录到 3 个关键词下

**修正**：全局 noteId 去重 + 每个 note 只保留首次命中的关键词

**结果**：去重率从 11.9% 提升到 18.3%（更多重复被识别）
